AGENT MINA ANDROID BRIDGE v0.1

Что умеет:
- Показывает приложения, у которых есть обычный значок запуска.
- Запускает выбранное приложение.
- Принимает ссылку вида:
  mina://launch?package=ИМЯ.ПАКЕТА

Важно:
- Это первая тестовая версия. Она НЕ управляет касаниями внутри других приложений.
- Для вызова из браузера Android может показать выбор приложения или запрос подтверждения.
- Не содержит Accessibility Service и не читает личные файлы.
- Список приложений ограничен Android-механизмом package visibility.

Сборка:
GitHub Actions workflow должен распаковать этот архив в корень временной папки и выполнить:
gradle assembleDebug

APK появится по пути:
app/build/outputs/apk/debug/app-debug.apk
